# P1 阶段项目

**学习优先级：** [必做 → 巩固 → 进阶](../../docs/课程大纲.md#学习优先级)。先完成课次“必做”及阶段验收；巩固按薄弱点补练，进阶不阻塞进度。每阶段维护一份实验记录，后续项目与报告复用已有成果。

当前为交付要求，完整实现待随课程完成。

## 项目增量

| 项目 | 约定 |
|---|---|
| 承接 | P0 的配置、能力报告、HTTP 排错习惯和 Pydantic 基础。 |
| 新增 | 将自然语言变成结构化 ResearchRequest，并对拒答、输入缺失和解析失败给出明确结果。 |
| 典型输入 | “用中文研究 2025 年本地 RAG，优先官方资料，最多检索 3 次。” |
| 预期行为 | topic=本地 RAG，time_range=2025 年，language=zh，source_requirements 包含官方资料，max_searches=3；表达可不同，含义必须一致。 |
| 失败处理 | 主题缺失需补充；明确非法预算不静默裁剪；内容格式最多修复一次；拒答、截断、超时和最终失败分别记录。 |
| 交付证据 | 解析器、输入输出约定、离线 Fixture 测试、至少 10 条固定评估输入和基线报告。 |

详细步骤及验收见 [P1 课程](../../docs/P1.md)。完成必做实验后再在本目录集成，不在每阶段重新实现上一阶段全部代码。
