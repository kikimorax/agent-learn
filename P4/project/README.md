# P4 阶段项目

**学习优先级：** [必做 → 巩固 → 进阶](../../docs/课程大纲.md#学习优先级)。先完成课次“必做”及阶段验收；巩固按薄弱点补练，进阶不阻塞进度。每阶段维护一份实验记录，后续项目与报告复用已有成果。

当前为交付要求，完整实现待随课程完成。

## 项目增量

| 项目 | 约定 |
|---|---|
| 承接 | P3 的研究工作流、只读工具边界、审批和预算。 |
| 新增 | 本地 Markdown/文本 PDF 检索、可定位引用、证据不足与冲突处理。 |
| 典型输入 | “青禾预算是多少？请给出处。”以及资料不存在答案或相互冲突的问题。 |
| 预期行为 | 每个事实有支持它的片段和来源；不足时说明缺失依据；冲突时列出相互矛盾的来源。 |
| 失败处理 | 无法提取的 PDF 明确报错；重复导入不累积重复记录；检索不到不等于资料明确否定。 |
| 交付证据 | 文档与元数据、导入/检索实现、引用映射、固定问题集、检索与回答质量报告。 |

详细步骤及验收见 [P4 课程](../../docs/P4.md)。完成必做实验后再在本目录集成，不在每阶段重新实现上一阶段全部代码。
