# P2 阶段项目

**学习优先级：** [必做 → 巩固 → 进阶](../../docs/课程大纲.md#学习优先级)。先完成课次“必做”及阶段验收；巩固按薄弱点补练，进阶不阻塞进度。每阶段维护一份实验记录，后续项目与报告复用已有成果。

当前为交付要求，完整实现待随课程完成。

## 项目增量

| 项目 | 约定 |
|---|---|
| 承接 | P1 的 ResearchRequest、失败结果与固定评估方法。 |
| 新增 | 三种只读工具、原生工具调用循环、预算、权限与有限重试。 |
| 典型输入 | “查青禾预算，并计算增加 20 元后的预算。”资料中预算为 100 元。 |
| 预期行为 | 取得资料并计算出 120 元，保存所用工具、参数、结果及最终汇总。 |
| 失败处理 | 未知工具、非法参数、缺资料、超时、重复调用和预算耗尽均能终止或按约定处理；写工具默认不开放。 |
| 交付证据 | 工具实现与 Schema、执行器、工具测试、完整轨迹和工作流/Agent 对照表。 |

详细步骤及验收见 [P2 课程](../../docs/P2.md)。完成必做实验后再在本目录集成，不在每阶段重新实现上一阶段全部代码。
