# P0 测试与评估

**学习优先级：** [必做 → 巩固 → 进阶](../../docs/课程大纲.md#学习优先级)。先完成课次“必做”及阶段验收；巩固按薄弱点补练，进阶不阻塞进度。每阶段维护一份实验记录，后续项目与报告复用已有成果。

以下为测试覆盖方向，先实现对应课次必做边界；扩展场景随巩固/进阶添加。当前开放能力的权限检查必须通过。

## 离线确定性测试

配置加载、环境变量优先级、HTTP 错误分类、响应提取；除现有配置测试外，其余为按课次补充的练习。

已有测试可在仓库根目录运行：

```powershell
uv run --project P0 pytest P0/tests shared/tests
```

用 Mock/Fixture 替换模型、工具或数据库时，明确替换边界。测试不应依赖真实密钥或运行中的模型网关；数据库和容器集成测试需另列前置条件。

## 模型行为与集成评估

使用固定输入和预先写好的预期行为，保存原始结果、耗时、模型/工具调用量与失败原因。真实模型评估和离线测试分开运行、分表报告；Mock 成功不证明模型质量或代理能力。

按 [P0 课程](../../docs/P0.md) 的完成证据验收。模型不可用时只标记离线测试结果，实际模型行为保持未验证；涉及持久化和部署的验收必须补真实集成记录。
