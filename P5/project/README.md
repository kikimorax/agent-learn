# P5 阶段项目

**学习优先级：** [必做 → 巩固 → 进阶](../../docs/课程大纲.md#学习优先级)。先完成课次“必做”及阶段验收；巩固按薄弱点补练，进阶不阻塞进度。每阶段维护一份实验记录，后续项目与报告复用已有成果。

当前为交付要求，完整实现待随课程完成。

## 项目增量

| 项目 | 约定 |
|---|---|
| 承接 | P1–P4 的固定案例、失败样例、轨迹、检索结果和离线测试。 |
| 新增 | 统一评分、版本比较、安全回归和阻止不合格版本发布的检查。 |
| 典型输入 | 同一批至少 20 条回归案例，在基线与候选版本上运行。 |
| 预期行为 | 报告逐例结果、成功率、延迟、调用量和失败层；权限或确定性检查失败时返回失败退出码。 |
| 失败处理 | 模型不可用时真实质量标记未验证；不删除失败样本，不以平均质量掩盖危险操作失败。 |
| 交付证据 | 回归集、评分规则、本地评估命令和一份质量/版本取舍记录；额外留出集为进阶。 |

详细步骤及验收见 [P5 课程](../../docs/P5.md)。完成必做实验后再在本目录集成，不在每阶段重新实现上一阶段全部代码。
