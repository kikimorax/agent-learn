# P3 阶段项目

**学习优先级：** [必做 → 巩固 → 进阶](../../docs/课程大纲.md#学习优先级)。先完成课次“必做”及阶段验收；巩固按薄弱点补练，进阶不阻塞进度。每阶段维护一份实验记录，后续项目与报告复用已有成果。

当前为交付要求，完整实现待随课程完成。

## 项目增量

| 项目 | 约定 |
|---|---|
| 承接 | P2 的原生循环、工具及预算/权限测试；不重写工具业务逻辑。 |
| 新增 | 规划、路由、审批、持久化、恢复与节点级日志。 |
| 典型输入 | 研究青禾项目；在计划生成后拒绝、同意或把检索预算改为 1。 |
| 预期行为 | 拒绝不搜索；同意按新预算继续；退出进程后可用同一 thread_id 恢复。 |
| 失败处理 | 非法审批不执行；不同 thread 状态隔离；重放和重试不会重复有效副作用。 |
| 交付证据 | 状态图、字段与 Reducer 说明、审批/重启测试、节点轨迹和原有工具回归。 |

详细步骤及验收见 [P3 课程](../../docs/P3.md)。完成必做实验后再在本目录集成，不在每阶段重新实现上一阶段全部代码。
