理解 Agent 的最小运行循环，学会设计可靠的工具，并能判断任务适合用 Agent 还是普通程序处理。

## 前置知识

- 能稳定获得文本或结构化模型输出。
- 会为普通 Python 函数编写单元测试。

## 知识范围（优先级见课次）

- Function Calling 请求、工具调用、工具结果回传和终止流程。

- 纯函数与有副作用工具；读取、写入和危险操作的权限分级。
- 超时、有限重试、退避、幂等键和最大工具调用次数。
- 确定性工作流、路由器和 Agent 循环的选择标准。
- 用原生协议手写并测试循环；LangChain `create_agent` 在 P3 正式学习。

### P2-01 普通函数变成工具

**要解决的问题：** 模型如何使用自己不知道的本地资料？

**概念与掌握程度：** 工具首先是普通函数；模型提出调用意图，程序执行函数并返回结果。只读函数与写入副作用要分清。

**本课用到的库：** Python 函数、pathlib；Pydantic 参数模型；本课不需要 LangChain。

**阅读入口：** [工具调用官方指南](https://developers.openai.com/api/docs/guides/function-calling) 阅读 Function calling flow；[练习目录](../P2/examples/README.md) 尚无实现。

### P2-04 多步循环与停止

**要解决的问题：** 模型连续请求工具时，程序何时结束？

**概念与掌握程度：** 循环有继续、成功结束、预算结束和错误结束；最大步数与总工具执行数不是同一个计数。

**本课用到的库：** while、显式计数器、单调时钟；工具注册表。

**阅读入口：** P2-03 的单次调用代码（待实现）；工具调用指南的连续回传示例。

### P2-05 超时、重试、预算与权限

**要解决的问题：** 工具失败时重复调用，会不会重复产生副作用？

**概念与掌握程度：** 瞬时故障可有限重试；非法参数需修正；写操作需要权限和幂等，不能靠 Prompt 保证。

**本课用到的库：** 超时控制、有限退避、幂等记录；pytest 的时钟与工具替身。

**阅读入口：** 前课执行器（待实现）；[asyncio Tasks](https://docs.python.org/3/library/asyncio-task.html) 阅读 Timeouts、Task cancellation。

#### 必做｜完成本课

1. 对只读工具模拟一次超时后成功，最多额外重试一次，重试计入预算。
2. 持续失败时停止，写工具默认关闭；用口头例子解释重试为何可能重复副作用。

**通过标准：** 有限重试与持续失败两个用例；完整写入幂等实现在 P3 学习。

**理解检查：** 超时不一定说明远端操作没执行；重复调用与重复副作用需分别处理。

## 阶段项目

构建一个研究 Agent：它能解析问题、选择本地资料搜索或计算工具、汇总结果，并在达到调用预算后停止。

### 阶段项目增量约定

| 项目 | 要求 |
|---|---|
| 承接成果 | P1 的 ResearchRequest、失败结果与固定评估方法。 |
| 本阶段新增 | 三种只读工具、原生工具调用循环、预算、权限与有限重试。 |
| 典型输入 | “查青禾预算，并计算增加 20 元后的预算。”资料中预算为 100 元。 |
| 预期行为 | 取得资料并计算出 120 元，保存所用工具、参数、结果及最终汇总。 |
| 失败处理 | 未知工具、非法参数、缺资料、超时、重复调用和预算耗尽均能终止或按约定处理；写工具默认不开放。 |
| 交付证据 | 工具实现与 Schema、执行器、工具测试、完整轨迹和工作流/Agent 对照表。 |

## 验收清单

本清单只验收必做主线。巩固和进阶可以不做；涉及测试“全部通过”时，指当前实现能力及必做边界的测试，不要求先实现所有扩展场景。若自行开放写入、网络访问等能力，其对应权限检查必须通过。

- [ ] 能从零实现一次完整的工具调用循环，不只依赖框架封装。
- [ ] 所有工具都有类型定义、Schema、明确的错误约定和单元测试。
- [ ] 写操作默认不可用，危险操作必须显式审批。
- [ ] Agent 遇到工具失败不会无限重试或崩溃。
- [ ] 能用数据说明何时普通工作流比 Agent 更合适。

## 常见失败

- 工具描述含糊，让模型靠猜选择工具。
- 把异常堆栈直接当作最终用户答案。
- 没有步数、时间或调用预算。
- 只在 Prompt 中要求检查权限，却没有在代码中落实。
